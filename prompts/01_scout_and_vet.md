# 01 SCOUT & VET
## /scout
Input: ONE niche (from the 200+ topics list) + target count. Find accounts via Instagram search "[topic] tips", hashtags, the "similar accounts" chevron next to Message, and "email for collabs/business inquiries" bios. Output: raw list (handle, followers, bio signal, link, last post date). Do NOT contact anyone.
## /vet (per account; run ALL gates, in order, stop at first RED)
Inputs needed: followers, last 12 posts (likes, comments, views, dates), 20 comment samples, Social Blade growth chart, bio/link, any existing product.
GATES
1 Size: 10K-100K. Else RED.
2 Like:comment ratio < 50:1. Above = inflated/passive audience. RED.
3 Originality: skill-based original content, no reposts/copyright exposure. RED if repost page.
4 Growth legitimacy: linear growth curves, sudden step jumps, mathematically impossible engagement = RED.
5 Comment quality: sample 20. Count genuine questions/requests ("how do I", "where can I get", "tutorial pls") = DOER/BUYER SIGNAL. Mostly emoji/bot/giveaway = AMBER/RED.
6 Posting reliability: >=3 posts/week for last 4 weeks (execution proxy). Else AMBER.
7 Existing monetization: has a product -> only pursue a real gap (subscription/upsell), else AMBER.
8 Management: represented by agency -> formal tone, address team.
MATH (run tools/revenue_model.py)
- NAIVE (workbook): followers x conversion(by ER) x price. Shown only to expose the gap.
- COMMENT-ANCHORED: buyer pool = avg comments x 3; sales = pool x {3%,8%,15%} (ASSUMPTIONS).
- FUNNEL: followers x story-view-rate x unique-click-rate x checkout-rate.
Headline the LOWEST scenario. Flag gap > 10x.
SCORES (0-100): Conversion Likelihood (warm signal 20, monetization intent 20, audience asks for help 15, active+consistent 15, contactable 10, size sweet spot 10-50K 10, niche/product fit 10) and Product-Fit (can we produce a $19-97 product a buyer would pay for, with no IP risk?).
OUTPUT: GREEN / AMBER / RED, both scores with evidence per point, math table, one-line "why this creator would say yes", biggest risk, send tier P1/P2/P3.
RULE: bad data gets flagged, not validated. If you cannot verify a number, write UNVERIFIED.
