## 7. Two smaller bugs

- `clearExistingTriggers_()` deletes **every** trigger in the Apps Script project, not just
  wave triggers. Anything else you automate there dies silently.
- A send error is logged and the loop **continues**. If the mailbox starts rejecting, the
  script keeps hammering and accelerates the problem.

## What I built instead

**`tools/audit_wave_lists.py`** — gates any wave list before it is scheduled. Checks
re-pitches (tracker + sent-mail exports), Gate G8 declines, live conversations, banned-niche
keywords, cross-wave duplicates, and volume vs the daily cap. Exits non-zero when blocked, so
it can run in CI. 17 tests.

**`gas/wave_autopilot_safe.gs`** — same intent, safe defaults:

| v4.4 | hardened |
|---|---|
| sends on install | `DRY_RUN: true`; `previewRun()` first |
| trigger installs itself | `installTrigger_()` **refuses** while any safety flag is armed |
| no suppression | suppression CSV enforced, generated by the audit tool |
| 288/day, 24/7 | 10/run, 25/day, 09:00–18:00 EAT only |
| fallback sends any draft | **no fallback** — explicit allowlist only |
| live leads re-pitched | `LIVE_THREAD_EMAILS` blocks them |
| errors logged, loop continues | aborts the run on first error |
| deletes all project triggers | only manages its own |

## If you want to run waves anyway

1. Fix the hook first. **130 touches bought 2 conversations; the on-niche batch bought 0.**
   Sending 288/day of the same copy multiplies a rate of zero.
2. Get off the primary inbox — warmed separate domain, before any volume.
3. Check the bounce rate on the 102-send batch (24–72h lag). `prompts/02`: stop at >3%.
4. Re-run the audit until it prints `CLEAR`, then fill `WAVES` in the hardened script.
5. Keep `DRY_RUN` on for the first full pass and read the log.

**The honest read:** at 1.5% positive across 130 touches, the constraint is not send
throughput. You have 99 quarantined leads, 29 contacted on-niche leads at 0 replies, and two
live conversations. There is no volume setting that fixes that — only a better offer and a
better hook.
