# MODELS — what this operation calls, and why

**Set:** 2026-10-31 · **Verified against:** Anthropic's deprecation table and models overview;
xAI's models page. Both fetched the same day, not remembered.

**Re-verify any time:**

```bash
curl -H "Authorization: Bearer $N8N_BRAIN_TOKEN" https://your-app.vercel.app/api/brain/models
```

That endpoint asks both providers what the account can actually call, then reports whether the ids
below still appear. A model id is a provider decision; this document is how you find out before a
member does.

---

## 1. The three lanes

Cost differs by ~20× across these, which is why they are three models and not one.

| Lane | Model | Price / MTok | Why this one |
|---|---|---|---|
| **quality** — script, rank, reframe, chat | `claude-sonnet-5-5` | $2 / $10 | Anthropic calls it "the best combination of speed and intelligence". 1M context, 128K output. A 60-second script is well inside its comfort zone at a price the $44 tier can carry. |
| **cheap** — classify, extract, route | `claude-haiku-5-5` | $0.10 / $0.50 | Anthropic names *classification, extraction and routing* as this model's purpose. The free tier allows 20 runs per 5 hours; a gate answer must not cost what a script costs. |
| **deep** — strategy, monthly plan | `claude-opus-5-5` | $4 / $20 | Opt-in only. Used where a wrong answer costs more than the call. |
| *frontier* — never default | `claude-fable-5-1` | $10 / $50 | Named in the price table so the cost model can see the ceiling. Not selected by any code path. |

**Grok, the second brain:** `grok-4.7` — xAI's current flagship, 500k context, $2 / $6. The
fallback should not be a downgrade; a fallback that writes worse scripts than the primary is a
silent quality cliff. `grok-4-1-fast` ($0.20 / $0.50) is the cheap-lane alternative if it is still
served — `/api/brain/models` says whether it is.

**What was there before:** `claude-3-5-sonnet-20241022`, retired by Anthropic on **2025-10-28**, and
`grok-2-latest`. Both were years out of date. The first 404'd on every request for a year while the
catch block returned a canned paragraph with HTTP 200.

## 2. The API changed ten days ago

Anthropic's `2026-10-21` version is not a rename. Three things break a client written before it:

| Change | Consequence |
|---|---|
| `temperature`, `top_p`, `top_k` **removed** | Sending any of them returns **400 on every model**. Every AI tutorial still sends temperature. |
| `output_config.effort` — `low \| medium \| high \| xhigh \| max` | The replacement lever. It controls how many tokens the model spends, not randomness. |
| `output_config.format` — `{type:"json_schema", schema}` | Structured output, GA, no beta header. This is what removed the prose-scraping in n8n. |

Two more that cost a debugging afternoon each:

- **Thinking counts against `max_tokens`.** Claude 5 thinks by default. A 512-token cap on a script
  returns `stop_reason: "max_tokens"` with **no text at all** — which reads as the model returning
  nothing. Default here is 8,192, clamped below the 21,333-token non-streaming ceiling.
- **`thinking: {type: "disabled"}` is a 400 on Sonnet 5.5.** So `thinking` is never sent. Silence is
  the only request that works across the whole line.
- **`stop_reason: "refusal"`** is a real outcome with no content blocks. Treated as its own code,
  not as a provider fault, because retrying it is arguing with a "no".

The schema sanitiser matters for the same reason: the API rejects `minimum`, `maximum`, `minLength`,
`maxItems > 1` and most `format` values **with a 400**. `sanitizeSchema()` moves those into
`description` (where they still steer the model) and closes every object with
`additionalProperties: false`. Any schema written by hand will contain at least one of them.

## 3. What each lane is worth in practice

System prompt ≈ 1,500 tokens, a script reply ≈ 800 tokens.

| Lane | Cost per call | 1,000 calls |
|---|---|---|
| cheap (haiku) | ~$0.0006 | $0.55 |
| quality (sonnet) | ~$0.011 | $11.00 |
| deep (opus) | ~$0.022 | $22.00 |

At 20 free runs per 5 hours per member, routing the gate questions to haiku and only the writing to
sonnet is the difference between a free tier that costs cents and one that costs dollars.

## 4. Where the model is chosen

`lib/brain.ts` is the only place. n8n does not name a model anywhere — it sends an `expect` value
(`script`, `rank`, `chat`, …) to `/api/brain` and the app decides. A model id typed into a workflow
would be a second source of truth, which is how the tier bug happened.

```
client → /api/jarvis ─┐
n8n    → /api/brain  ─┴→ lib/jarvis.ts → lib/brain.ts → laneFor(expect) → modelId() → provider
```

Env overrides, all optional:

| Variable | Effect |
|---|---|
| `ANTHROPIC_MODEL` | pins the quality lane |
| `ANTHROPIC_MODEL_CHEAP` | pins the cheap lane |
| `ANTHROPIC_EFFORT` | forces one effort level for every call |
| `GROK_MODEL` | pins the fallback |

A **retired** id in any of these is detected and replaced rather than allowed to 404, and the
substitution is reported in the response — `B01` tests it.

## 5. Tests that hold this

| Test | Prevents |
|---|---|
| `B01` | a retired id being sent, or `DEFAULT_MODEL` silently ageing into one |
| `B08` | the old request shape (no `output_config`, wrong API version, sampling params) |
| `B09` | a classification costing a script's price |
| `B10` | effort collapsing to the default for every lane |
| `B11` | a schema keyword that returns 400 being sent |
| `B12` | a refusal being retried as an outage |
| `B13` | a truncated thinking budget looking like an empty reply |
| `B14` | the Grok fallback pointing at a museum piece |
| `B15` | a configured model that the account no longer has |

Each was negative-tested: reverting the request shape fails `B08`; disabling the sanitiser fails
`B11`; pointing a lane at the wrong model fails `B09`.
